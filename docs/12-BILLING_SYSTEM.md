# Billing System Architecture

# Pricing Plans

## Free

$0/month

Includes:

- 1 active bundle
- Basic widget
- Shopify branding

---

$19/month

- Unlimited bundles
- Templates
- Customization

---

## Growth

$39/month

- Analytics
- Remove branding

## Pro

$79/month

- Multiple stores
- Advanced reports

# Shopify Billing Flow

Merchant selects plan

↓

Create Shopify subscription

↓

Shopify approval

↓

Save subscription status

↓

Enable features
