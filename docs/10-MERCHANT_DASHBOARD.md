# Merchant Dashboard Architecture

## Purpose

Provide Shopify merchants a simple interface to create and manage bundles.

---

# Dashboard Structure

/dashboard

Pages:

## Home

Shows:

- Revenue generated
- Active bundles
- Performance overview

---

## Bundles

Features:

List bundles

Columns:

- Name
- Status
- Revenue
- Actions

Actions:

- Edit
- Duplicate
- Delete

---

## Create Bundle Wizard

Steps:

Step 1:

Choose template

Step 2:

Select products

Step 3:

Set discount

Step 4:

Customize design

Step 5:

Publish

---

## Analytics

Shows:

- Bundle views
- Adds
- Purchases
- Revenue
- Conversion rate

---

## Settings

Contains:

- Store settings
- Billing
- Support

---

# UI Requirements

Design:

- Simple
- Premium
- Beginner friendly

Target user:

Non technical Shopify merchant.
