# Analytics System Architecture

## Purpose

Track bundle performance and merchant revenue impact.

---

# Events

System tracks:

## Bundle View

When customer sees bundle.

Event:

bundle_view

---

## Add To Cart

When customer adds bundle.

Event:

bundle_add

---

## Purchase

When bundle order completes.

Event:

bundle_purchase

---

# Analytics Data

Store:

- Event type
- Bundle ID
- Shop ID
- Revenue
- Timestamp

---

# Dashboard Metrics

Display:

## Bundle Revenue

Total revenue generated.

## Orders

Number of bundle purchases.

## Conversion Rate

Views compared to purchases.

## AOV Increase

Revenue improvement.

---

# Future Analytics

Support:

- Revenue reports
- Export CSV
- Advanced charts
- Customer insights
